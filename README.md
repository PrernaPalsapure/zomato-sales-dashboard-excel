# Food Delivery Data Analysis Dashboard in Excel

## Project Overview

This project focuses on cleaning, analyzing, and visualizing a large food delivery dataset using Microsoft Excel. The dashboard provides business insights related to restaurant performance, customer engagement, pricing trends, and bestseller categories.

The project includes:
- Data Cleaning
- Missing Value Handling
- Pivot Table Analysis
- Interactive Dashboard Creation
- Business Insight Generation

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas

---

## Dataset Information

The dataset contains 120,000+ rows of restaurant and food delivery data.

### Columns Included:
- Restaurant Name
- Dining Rating
- Delivery Rating
- Dining Votes
- Delivery Votes
- Cuisine
- City
- Place Name
- Item Name
- BestSeller Category
- Votes
- Prices

---

## Data Cleaning Process

The following cleaning operations were performed:

- Handled missing values
- Replaced blank BestSeller entries with "NORMAL"
- Removed extra spaces using TRIM()
- Standardized categorical values
- Created helper columns for analysis
- Investigated duplicate records
- Validated ratings and price values

---

## Dashboard Features

The dashboard includes:

- KPI Cards
- Top 10 Restaurants by Votes
- Average Prices by Cuisine
- Bestseller Category Distribution
- City-wise Average Ratings
- Top 10 Premium Food Items
- Interactive Slicers

---

## Key Insights

- BESTSELLER items dominate customer engagement
- Higher-rated restaurants generally receive more votes
- Premium food items attract high customer interaction
- Cuisine categories show noticeable pricing differences
- Hyderabad restaurants showed strong average ratings
